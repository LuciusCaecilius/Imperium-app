# **App Name**: VaultCraft

## Core Features:

- Vault Overview: Display available vaults with APY, TVL, and other key metrics.
- USDC/gUSDC Conversion: Convert USDC to gUSDC within the app.
- Vault Deposit: Deposit gUSDC into selected vaults and receive receipt tokens.
- Vault Withdrawal: Withdraw gUSDC from vaults by burning receipt tokens.
- Risk Score Generation: AI-powered tool to generate risk score to access risk associated with each vaults, enabling better decisions regarding deposit distribution based on risk preferences. It should access Chainlink for latest defi security reports.
- Transaction History: Provide transaction history for all deposits, withdrawals, and conversions.

## Style Guidelines:

- Primary color: Rich gold (#D4AF37) to convey luxury and sophistication.
- Background color: Deep charcoal gray (#1A1A1A) for a high-end, exclusive feel; complements the gold accents.
- Accent color: Muted bronze (#8B7355), analogous to the gold, adds subtle contrast and warmth to the interface.
- Font pairing: 'Playfair' (serif) for headings to evoke a sense of elegance, combined with 'PT Sans' (sans-serif) for body text to maintain readability.
- Custom-designed icons with a minimalist, geometric style, rendered in the primary gold color (#D4AF37) and animated on hover.
- Use a grid-based layout with ample spacing to create a clean and organized presentation. Highlight key information with strategically placed visual cues.
- Incorporate smooth transitions and micro-interactions to enhance user engagement. Examples include vault entries sliding in when revealed, subtle pulsing on key action buttons, and value increases utilizing 'number go up' animations.
